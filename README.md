# 2026 高考英语 · 全国 I 卷 听力练习

自包含 HTML 听力练习页：**20 道真题 + 裁剪好的对应音频片段 + 逐句高亮原文**，浏览器直接打开或用下面的 Pages 链接。

- 在线访问: https://huhehen.github.io/gaokao-2026-listening/listening.html
- 本地使用: 解压后直接打开 `listening.html`（`clips/` 与 html 同目录）

## 功能
- 每道题下方挂该录音的裁剪片段（首遍播放），选错即时显示正确答案
- 原文默认折叠；展开后**播放到哪句高亮哪句**（黄色）
- **答案证据句整句标蓝**；每行带 M./W. 说话人标签
- 点击任意一句 → 从该句重读
